# Karaoke Party

A modern web application for managing karaoke song lists with a mobile-first design. Built with React, Express, and modern web technologies.

## Features

- Mobile-optimized touch interface with smooth scrolling
- Pull-to-refresh functionality
- Elastic scrolling effects
- Song list management (add/remove songs)
- Real-time song list updates
- Responsive design that works on both mobile and desktop

## Prerequisites

- Node.js (v14 or higher)
- npm (v6 or higher)

## Installation

1. Clone the repository:
```bash
git clone [repository-url]
cd karaoke-party
```

2. Install dependencies:
```bash
npm install
```

3. Start the development server:
```bash
npm run dev
```

4. In a separate terminal, start the backend server:
```bash
node server.js
```

The application will be available at:
- Frontend: http://localhost:5173
- Backend: http://localhost:3000

## Development

- Frontend is built with React + Vite
- Backend uses Express.js
- Styling uses Tailwind CSS and CSS Modules
- Mobile-first design with touch interactions
